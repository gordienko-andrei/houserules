# Houserules

ESLint plugin and CLI for enforcing project house rules.

## Packages

| Package | Description |
| --- | --- |
| [`eslint-plugin-houserules`](packages/eslint-plugin) | ESLint rules |
| [`houserules`](packages/cli) | Command-line interface |

## Development

Requires Node.js 22+ and pnpm.

```sh
pnpm install
pnpm test
pnpm typecheck
```
